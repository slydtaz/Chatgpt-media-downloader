# Código de Conduta

Esperamos que participantes ajam com respeito, empatia e espírito colaborativo. Contribuições devem ser construtivas e focadas no código, na documentação e na experiência de uso.

Não serão tolerados assédio, insultos, ataques pessoais, discriminação, publicação de dados privados, ameaças ou comportamento deliberadamente disruptivo.

Mantenedores podem editar, fechar ou remover contribuições que violem estas regras e limitar a participação em caso de reincidência. Para reportar uma situação, use os canais privados disponibilizados pelos mantenedores; não publique dados pessoais de ninguém.
