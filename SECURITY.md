# Política de segurança

## Declaração de segurança

O código foi desenvolvido para baixar mídia com ferramentas de código aberto e **não foi criado para conter vírus ou funcionalidades maliciosas**. Até onde foi verificado pelo mantenedor, não há malware intencional conhecido. Isso não substitui auditoria independente, assinatura digital ou análise do binário: não é correto prometer que qualquer build estará 100% livre de vírus ou falsos positivos.

Para reduzir riscos, prefira compilar a partir do código-fonte revisado ou baixar arquivos da seção **Releases** deste repositório, conferir o SHA-256 publicado e analisar o arquivo com seu antivírus. Arquivos gerados localmente por forks não são releases oficiais deste projeto.

## Como reportar uma vulnerabilidade

Não publique detalhes de vulnerabilidades em Issues, Discussions ou Pull Requests públicos. Use o recurso **Report a vulnerability / Security advisories** na aba Security do GitHub, se estiver disponível no repositório. Envie uma descrição, impacto, passos mínimos para reproduzir e uma forma segura de contato. Não inclua senhas, cookies, tokens ou dados de terceiros.

Se o recurso não estiver habilitado, abra apenas um issue genérico solicitando um canal privado, sem incluir detalhes técnicos da falha até haver um canal seguro.

## Escopo e manutenção

O aplicativo usa dependências externas, incluindo yt-dlp, FFmpeg e FFprobe. Uma vulnerabilidade pode estar no aplicativo, no empacotamento ou numa dependência; informe, quando possível, versão do programa, sistema operacional e versão da dependência afetada.
