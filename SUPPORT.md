# Ajuda e suporte

- **Erro no aplicativo:** [abra um bug report](https://github.com/slydtaz/chatgpt-media-downloader/issues/new?template=bug_report.yml).
- **Nova ideia:** [envie uma feature request](https://github.com/slydtaz/chatgpt-media-downloader/issues/new?template=feature_request.yml).
- **Dúvidas já reportadas:** [veja os Issues existentes](https://github.com/slydtaz/chatgpt-media-downloader/issues).
- **Downloads oficiais:** [abra Releases](https://github.com/slydtaz/chatgpt-media-downloader/releases).

Ao pedir ajuda, informe a versão e o sistema operacional e inclua passos para reproduzir. Redija logs antes de compartilhar para remover tokens, cookies, URLs privadas, nomes de usuário e outros dados pessoais.
