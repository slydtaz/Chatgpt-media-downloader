# v4.2.0 — interface e preferências

- Configurações, Dependências, Ajuda e Desenvolvedor agora são páginas dentro da janela principal.
- Tema claro, escuro e Sistema.
- Contraste de texto reforçado.
- Tooltip `?` em configurações: aparece após 2 segundos de foco do mouse e pode ser fixado com clique.
- Botão explícito para salvar configurações.
- Reversão individual para `Padrão` ou `Inicial`.
- Reversão completa para `Padrão` e para a configuração inicial registrada após a preparação de dependências.
- Linux usa caminhos de saída nativos e cria entrada `.desktop` com `Terminal=false`.
- Bootstrap registra um baseline de instalação para permitir restauração posterior.
- Launcher Windows continua sem console visível quando `wscript/pythonw` estiver disponível.
