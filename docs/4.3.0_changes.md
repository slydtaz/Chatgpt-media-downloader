# v4.3.0 — substituição segura da instalação e atalho automático

- Ao iniciar um pacote novo fora da instalação, o bootstrap procura instalações antigas pertencentes ao produto em locais de aplicativos e as remove somente quando o marcador interno confirma `Vendor=ChatGPT` + `Product ID=com.chatgpt.mediadownloader`.
- A nova cópia é então instalada na pasta identificada pelo Install ID.
- O conteúdo de uma instalação própria antiga é substituído em vez de ser misturado com arquivos de versões anteriores.
- A Área de Trabalho é detectada pelo Windows via `WScript.Shell.SpecialFolders("Desktop")`, inclusive em cenários de redirecionamento/OneDrive.
- O atalho `ChatGPT Media Downloader.lnk` é recriado automaticamente em cada inicialização da cópia instalada, caso tenha sido removido.
- Nenhuma pasta de outro aplicativo é apagada: pastas sem o marcador de propriedade correto são preservadas.
- A configuração e os downloads ficam fora da pasta da aplicação e não são removidos durante a atualização.
