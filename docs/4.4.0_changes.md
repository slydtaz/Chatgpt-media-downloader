# v4.4.0 — miniaturas incorporadas, processos silenciosos e atualização segura

## Download de vídeo
- Usa `--embed-thumbnail` e `--embed-metadata` via yt-dlp/FFmpeg para incorporar a thumbnail ao contêiner de vídeo.
- Usa remux MP4 para favorecer suporte a cover art sem recodificar o vídeo quando o codec/container permite.
- Não ativa `--write-thumbnail`; assim, a thumbnail é temporária e o postprocessador do yt-dlp remove-a após processá-la. Não é criado um arquivo lateral de imagem pela configuração do app.

## Interface e responsividade
- `Tooltip.dismiss_all()` cancela atrasos e fecha tooltips fixados quando uma página é selecionada.
- Inspeção de dependências passou para uma thread de trabalho e retorna à GUI via fila.
- A fila limita o número de eventos processados por ciclo e atualiza a cada 50 ms para reduzir congelamentos em rajadas de logs/progresso.

## Processos de fundo
- Criado `app/process_utils.py` para aplicar `CREATE_NO_WINDOW` e `STARTUPINFO` oculto no Windows.
- Aplicado à execução e inspeção do yt-dlp/FFmpeg, incluindo a validação de binários baixados.
- O programa continua usando argumentos como lista; não introduz `shell=True`.

## Atualizador/instalador
- Agora prepara a versão nova em staging, verifica os arquivos essenciais, o Product ID e o Install ID antes de substituir a pasta.
- A instalação anterior é movida para backup antes da troca; se a troca falhar, o bootstrap tenta restaurá-la.
- Instalações antigas só são removidas depois de uma cópia nova validada.
- Os diretórios nomeados `ChatGPT Media Downloader-*` na pasta `/Applications` também são reconhecidos como possíveis instalações próprias no macOS.

## Limites de verificação
- Testes unitários e smoke test da GUI são executados localmente no pacote.
- Não se declara um download real em um serviço externo nem uma execução no Windows do usuário sem o respectivo ambiente e acesso externo.
