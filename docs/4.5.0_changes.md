# v4.5.0 — playlists e fluxo de download

- Detecta padrões comuns de URL de playlist e mostra aviso vermelho na página principal.
- Pede confirmação antes de baixar todos os itens.
- Usa o modo e a qualidade/bitrate escolhidos para cada item.
- Organiza itens em subpasta da playlist com índice para evitar nomes repetidos.
- Limpa o log visual ao iniciar um novo trabalho.
- Mantém downloads via yt-dlp, incorporação de thumbnail/metadados, processos sem console no Windows e arquitetura multiplataforma.

Limitação: a detecção visual usa padrões de URL, não faz uma consulta remota de preflight. Playlists que não indiquem playlist no caminho/query podem não exibir o aviso; o yt-dlp continua determinando o suporte real do site.
