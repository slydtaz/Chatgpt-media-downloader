# v4.6.0 — bloqueio entre instâncias e recuperação de inicialização

- Adicionado bloqueio por arquivo com semântica de exclusão entre processos; funciona no Windows e em sistemas POSIX.
- O bloqueio fica no diretório de dados comum entre versões instaladas, evitando que duas instâncias compatíveis com a trava façam manutenção ao mesmo tempo.
- Migração instala os arquivos e valida a árvore antes de iniciar handoff tokenizado para o launcher instalado.
- Uma segunda inicialização recebe mensagem clara em vez de repetir a instalação/atualização por trás da interface.
- Verificações de dependências e download dos binários rodam em worker thread com event loop Tk ativo, corrigindo a aparência de “Não está respondendo”.
- Binários são descarregados em diretório temporário dentro de `tools`, validados antes da promoção final, e substituições falhas preservam os arquivos anteriores quando possível.
- FFmpeg e FFprobe são substituídos como conjunto transacional com rollback em caso de erro.
- O programa bloqueia instalação de dependências pela GUI durante um download ativo.
- Adicionados testes de bloqueio, handoff, promoção atômica e rollback.

Limitação de recuperação: processos de versões anteriores que já estavam travados antes da instalação da v4.6.0 não usam o novo bloqueio. Encerre essas instâncias antigas pelo Gerenciador de Tarefas antes de iniciar a v4.6.0 pela primeira vez.
