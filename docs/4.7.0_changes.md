# v4.7.0 — diagnóstico de playlist e atualização de miniaturas

- O processo que retorna código não zero mas contém o marcador final de playlist agora é classificado separadamente como “concluído com avisos”; o código original é mantido para diagnóstico.
- A GUI informa que itens indisponíveis podem existir sem alegar que todos os downloads falharam.
- Após download, o programa notifica o Shell do Windows para atualizar os arquivos de mídia recentes. Isso solicita refresh da miniatura existente; não instala extensões nem garante que a instalação do Windows gere miniaturas MP3.
- A documentação diferencia capa embutida no MP3 (confirmada pelo passo `EmbedThumbnail`) da miniatura que o Explorador mostra. Inclui as opções para ativar miniaturas no Windows.
- Testes acrescentados para o marcador de conclusão de playlist e para o comportamento não-Windows da notificação.

Limitação testada/documentada: o conteúdo de capa é incorporado pelo yt-dlp/FFmpeg quando o site fornece uma thumbnail. A exibição como miniatura na shell depende das configurações/handlers do Windows e deve ser verificada no PC do usuário.
