# v4.8.0 — distribuição em executável único

- Adicionado entrypoint `packaged_entry.py` e uma receita PyInstaller one-file sem console.
- Adicionado `build_exe.bat`, que gera `dist/ChatGPTMediaDownloader.exe` no Windows.
- Adicionado workflow GitHub Actions que compila e publica o EXE como artifact em um runner Windows.
- O EXE se instala automaticamente numa pasta própria identificada por Product ID + Install ID e usa troca transacional com validação SHA-256 do arquivo copiado.
- A criação do atalho da Área de Trabalho passa a apontar diretamente para o EXE instalado, sem exigir `.vbs`.
- A instalação também pode criar entrada `.desktop` no Linux ao distribuir a build nativa única.
- No modo frozen, dependências baixadas são mantidas na área de dados do usuário, não no diretório temporário `_MEIPASS` nem em `Program Files`.
- O artefato final deve ser compilado na plataforma-alvo; esta revisão não afirma que o EXE Windows foi compilado neste ambiente Linux.
