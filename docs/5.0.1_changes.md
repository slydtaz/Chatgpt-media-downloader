# ChatGPT Media Downloader 5.0.1

## Mudanças

- O build de Windows `build_exe.bat` gera agora o executável único `dist\ChatGPTMediaDownloader.exe` e o respectivo `dist\SHA256SUMS.txt`.
- O verificador de atualização entende Releases publicadas sob a tag-alias `stable`, desde que o título da Release contenha a versão semântica, por exemplo `ChatGPT Media Downloader 5.0.1 — Stable`.
- Atualizada a documentação para recomendar o executável oficial aos usuários comuns e indicar o ZIP de código-fonte para desenvolvedores.

## Build

Execute `build_exe.bat` no Windows, na raiz do projeto, ao lado de `launcher.vbs` e `ChatGPTMediaDownloader.spec`. Teste o executável antes de anexá-lo a uma Release.
