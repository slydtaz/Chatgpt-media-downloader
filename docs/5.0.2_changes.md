# ChatGPT Media Downloader 5.0.2

## Correções da publicação e atualização

- O publicador consulta a tag remota `stable` por uma referência temporária, resolve-a para o commit real e só a move depois de confirmação explícita.
- O workflow de release é acionado por `stable` e por tags `v*`; no Windows executa os testes, compila um EXE de arquivo único e publica o hash SHA-256.
- O atualizador procura primeiro a Release `stable`, evitando depender de uma Release de versão antiga configurada como `latest`.
- A compilação sintática no GitHub Actions usa `pathlib` para enumerar os arquivos, compatível com PowerShell no runner Windows.
- O teste de exclusão mútua entre processos usa arquivo de prontidão e timeout em vez de uma leitura bloqueante do pipe.
- O workflow de página tenta habilitar GitHub Pages antes de publicar o site.

## Limitações

O build de Windows deve ser executado em Windows. A Release é considerada pronta para usuários somente quando o workflow termina com sucesso e apresenta os assets `ChatGPTMediaDownloader.exe` e `SHA256SUMS.txt`.
