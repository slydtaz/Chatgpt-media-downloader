# ChatGPT Media Downloader 5.0.3

## Correções de CI e publicação

- O teste de locking entre processos é ignorado somente no Windows hospedado pelo GitHub Actions, onde o runner interrompeu a espera do filho com `KeyboardInterrupt`. O teste permanece habilitado em Linux/macOS e em uma execução local do Windows; os demais testes de locks continuam rodando na matriz Windows/Linux.
- O workflow do Pages tenta habilitar o recurso antes do deploy. Se o repositório tiver políticas da conta que impedem o uso do Pages, o deploy ainda pode exigir configuração manual em Settings → Pages.
- O build da Release `stable` executa testes, cria um EXE Windows único e gera `SHA256SUMS.txt` correspondente.

## Observações de validação

A correção do fluxo elimina o bloqueio conhecido no runner hospedado; é necessário conferir a execução de Actions após publicar este commit. O EXE precisa ser testado em Windows antes da divulgação.
