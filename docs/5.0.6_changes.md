# ChatGPT Media Downloader 5.0.6

## Correção dos runners Windows

Os logs do GitHub Actions mostraram que a etapa do `unittest` terminava de maneira anormal ao imprimir os resultados em `stderr`. A tentativa de redirecionar a saída com `2>&1` no PowerShell não resolveu o problema. Os workflows de Windows agora usam `shell: cmd` para comandos Python nativos — compilação sintática, testes e PyInstaller — enquanto os testes em Ubuntu continuam usando Bash.

Foi acrescentado um teste de regressão que verifica a separação dos shells nos workflows.

## Validação remota

A matriz da PR de correção passou nos quatro jobs do GitHub Actions: Windows/Python 3.10, Windows/Python 3.12, Ubuntu/Python 3.10 e Ubuntu/Python 3.12. Uma execução separada em Windows também passou pelos testes, gerou o executável único, calculou o SHA-256 e fez upload do artefato. A compilação final da versão 5.0.6 deve ser concluída antes de anunciar a Release `stable`.

## Publicação de recuperação

O pacote do mantenedor contém um caminho manual para construir o EXE no Windows, verificar seu hash e criar a Release `stable` quando ela ainda não existir. O upload deve ser feito somente depois de testar o executável e validar o manifesto `SHA256SUMS.txt`.
