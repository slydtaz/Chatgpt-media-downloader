# ChatGPT Media Downloader 5.0.6

## Correção do runner Windows

Os logs do GitHub Actions mostraram que a etapa de testes terminava prematuramente ao imprimir o relatório do `unittest` em `stderr`. A tentativa de mesclar streams com `2>&1` no workflow PowerShell não resolveu o problema: a execução 5.0.5 também falhou antes de concluir a suíte.

Nesta versão, a matriz usa `shell: cmd` exclusivamente para executar o `unittest` em Windows e mantém `shell: bash` nos runners Unix. Os workflows de release e build manual, que executam somente em Windows, também usam `cmd` no passo de testes. Isso deixa o status do passo dependente do código de saída real do Python.

Foi adicionado um teste de regressão para impedir a remoção acidental dessa separação. A correção só deve ser considerada confirmada depois que o novo workflow remoto completar os testes, gerar o EXE e calcular o checksum com sucesso.

## Caminho alternativo de publicação

O script `PUBLISH_EXE_TO_STABLE.bat` agora valida o SHA-256 do executável local e consegue criar a Release `stable` com os dois arquivos se ainda não existir; caso já exista, substitui os assets e atualiza o título. Esse caminho exige gerar e testar o EXE localmente em Windows antes do upload.
