# ChatGPT Media Downloader 5.1.0 - stable

## Correção do auto-update e proteção contra downgrade

O bootstrap agora detecta uma instalação existente mais recente e não a sobrescreve com arquivos de um executável portátil ou árvore-fonte antiga. Quando a nova instalação é iniciada no Windows, tenta sincronizar a entrada EXE portátil original com o executável instalado, verificando tamanho e SHA-256.

## Descoberta de versões

O atualizador consulta primeiro a Release versionada mais recente e só recorre à Release histórica `stable` quando necessário. Assim, as futuras Releases estáveis podem ser listadas como `x.x.x - stable` sem renomear a primeira Release da tag `stable`.

## Redesign visual

A interface foi redesenhada com barra de navegação lateral, área de trabalho, painel de download e cartões de sessão, inspirada em launchers modernos sem copiar recursos ou ativos proprietários do SK Launcher. Foram adicionados os temas Escuro, Claro e Preto OLED, cor de destaque HEX com seletor e paletas rápidas, além de densidade Compacta ou Confortável.

## Validação

A validação local passa pela compilação sintática, suíte unitária e smoke test de interface em Xvfb. O workflow GitHub Actions também executará testes em Windows/Ubuntu e construirá o EXE em runner Windows antes da publicação.
