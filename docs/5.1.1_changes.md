# ChatGPT Media Downloader 5.1.1 - stable (hotfix-1)

## Falha crítica identificada

O fluxo de reparo de inicialização mostrava a mensagem de sucesso assim que iniciava o auxiliar, sem verificar se a substituição havia terminado nem se a aplicação nova realmente conseguia abrir. O auxiliar era um processo separado; falhas na troca ou no reinício podiam deixar a versão anterior instalada, enquanto o próximo lançamento repetia a mesma pergunta de reparo. Os erros do auxiliar eram gravados em um arquivo temporário, sem confirmação de retorno à aplicação.

## Correção

- O auxiliar do Windows agora escreve diagnóstico persistente em `%LOCALAPPDATA%\ChatGPT\MediaDownloader\logs\update-helper.log`.
- A cópia de preparação do executável é validada por SHA-256 no destino antes da promoção; a substituição tenta novamente quando o arquivo estiver momentaneamente bloqueado.
- O backup anterior permanece disponível até a nova interface confirmar a abertura. Quando a troca falha antes de confirmar a nova versão, a cópia anterior é restaurada quando possível.
- O reparo de inicialização deixa um marcador persistente que a nova interface limpa depois de construir a janela principal. Se isso não acontecer, a próxima tentativa interrompe o ciclo automático e apresenta o link oficial para recuperação manual.
- O auxiliar exibe uma mensagem de erro visível com o caminho do log quando não consegue concluir a troca/reabertura.

## Recuperação de usuários presos na versão 5.0.1

A instalação 5.0.1 contém o auxiliar antigo, que não dispõe desta confirmação. Como o reparo automático anterior pode falhar antes de instalar o código corrigido, o caminho confiável para sair do ciclo é baixar manualmente o executável oficial desta release e executá-lo uma vez:

https://github.com/slydtaz/Chatgpt-media-downloader/releases/latest

A tag histórica `stable` é preservada; esta correção usa a tag de versão `v5.1.1`. Não é necessário remover preferências ou mídias baixadas.

## Validação

Os testes automatizados adicionam cobertura para o marcador do reparo, a supressão da pergunta repetitiva, e as garantias documentadas no auxiliar Windows. O workflow de release executa a suíte, a compilação sintática e o build PyInstaller em um runner Windows antes de publicar. O teste unitário do helper verifica o conteúdo do script; o teste de instalação completa no computador do usuário continua separado e não é declarado como executado.
