# ChatGPT Media Downloader 5.1.2 — stable (hotfix-2)

## Recuperação após erro crítico

A tela exibida quando o bootstrap falha agora oferece três opções explícitas: **Tentar reparar**, **Desinstalar aplicativo** e **Cancelar**. Quando uma tentativa anterior ficou pendente, o usuário ainda pode escolher tentar novamente; nenhum ciclo de reparo novo é iniciado sem ação explícita.

O instalador do executável prioriza uma localização por usuário no Windows, onde o usuário atual consegue substituir arquivos sem privilégios administrativos. Isso corrige um modo concreto de falha do reparo: uma cópia instalada em Program Files podia ser atualizada pelo auxiliar sem que o processo tivesse autorização de escrita.

## Desinstalador

A página Atualizações inclui a opção de desinstalar. Antes de remover uma pasta da instalação, o desinstalador exige o marcador do aplicativo com o fornecedor e Product ID esperados. As configurações, ferramentas e logs guardados em `%LOCALAPPDATA%\ChatGPT\MediaDownloader` são removidos. As pastas onde o usuário baixou músicas e vídeos são separadas e não são removidas. A remoção de instalações de sistema pode solicitar UAC.

## Identificação do executável

O build inclui um recurso de versão PE com versão do produto, nome do executável, descrição, copyright, aviso de não afiliação e URL do repositório. Esses metadados ajudam a identificar o arquivo nas propriedades do Windows, mas **não são uma assinatura digital**.

O workflow agora suporta assinatura Authenticode e verificação por SignTool quando o mantenedor configura um certificado confiável nos secrets do GitHub. Sem certificado, publica um arquivo de status informando que o EXE continua não assinado. Não foi inventado nome empresarial nem certificado.

## Validação e limitações

Os testes de CI verificam a lógica de migração para instalação por usuário, as opções de recuperação e os metadados PE; o build ocorre no runner Windows. O fluxo real no computador que apresentou o erro ainda depende de reproduzir a falha nele com a nova versão. Se a nova Release não estiver assinada, o SmartScreen ainda pode alertar sobre editor desconhecido, mesmo com os metadados preenchidos.
