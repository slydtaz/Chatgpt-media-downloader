# ChatGPT Media Downloader 5.1.3 — stable (hotfix-3)

## Correção da janela vazia

O início da GUI agora usa uma janela raiz Tk oculta enquanto os widgets são criados. A janela é revelada só depois que a construção da interface termina e o layout inicial foi processado. Isso impede que uma falha durante a construção deixe o usuário olhando para a janela-padrão azul-escura do Tk, sem qualquer conteúdo.

Se a criação da interface ou o loop principal lançar uma exceção, o aplicativo grava o traceback em `%LOCALAPPDATA%\ChatGPT\MediaDownloader\logs\app.log`, fecha a janela parcial e relança a exceção para o bootstrap. O bootstrap pode então mostrar a tela de recuperação em vez de ficar encoberto por uma janela vazia.

## Animações e visual

- Adiciona navegação com transições de deslizamento curtas entre as páginas.
- Adiciona um elemento visual em Canvas no painel inicial: anéis e partículas violetas com movimento lento, usando apenas Tkinter/Canvas e sem recursos gráficos pesados.
- Mantém as animações leves para não exigir GPU ou dependências adicionais. As páginas continuam utilizáveis se as animações não puderem continuar durante o fechamento da janela.
- A direção visual usa referências gerais do SKlauncher 4.0 Beta — superfície azul-marinho, acentos violetas, composição moderna em cartões e movimento sutil — sem copiar identidade, logotipos ou assets do produto original.

## Testes

Adiciona testes que simulam falha durante a construção da GUI e verificam que a janela permanece oculta, é destruída e não entra no event loop. Outro teste confirma que a janela só é exibida após a montagem do layout. A matriz automatizada executa em Windows e Ubuntu, Python 3.10 e 3.12.

A validação de CI cobre construção de widgets simulada e sintaxe do código; a reprodução exata do problema no computador do usuário ainda depende de obter seu log local se a versão 5.1.3 continuar apresentando falha.
