# Versão 5.3.0 — segurança, confiança e interface profissional

## Interface

- Adota uma identidade visual profissional em azul e cinza, com botões sólidos e hierarquia visual mais discreta.
- Simplifica textos da janela e da central de downloads para uma experiência mais próxima de um aplicativo de desktop convencional.
- Novas instalações começam com animações desativadas; a preferência já existente de cada pessoa continua preservada.
- Migra somente o antigo roxo padrão para o novo azul. Cores personalizadas continuam intactas.

## Segurança

- Endurece a validação de URLs e remove credenciais de URLs redigidas nos logs.
- Rejeita travessia de diretórios, links simbólicos e entradas especiais na extração de arquivos ZIP/TAR.
- Valida protocolo, host final após redirecionamento e tamanho nos downloads de dependências.
- Exige manifesto SHA-256 válido para instalação automática de dependências; não trata ausência de checksum como confiança.
- Fixa versões e revisões de actions na automação e fixa as ferramentas de build.
- Expande testes para URLs inválidas, caminhos de arquivo compactado e validação de checksum.

## Limites declarados

- Os executáveis do Windows continuam sem assinatura Authenticode até o mantenedor configurar um certificado de assinatura de código confiável.
- Hashes, testes automatizados e proveniência de build melhoram a rastreabilidade, mas não equivalem a certificação ou auditoria independente.
