Projeto de código aberto · versão-fonte 5.0.1

ChatGPT Media Downloader

Uma interface gráfica para baixar vídeos, extrair áudio em MP3 e selecionar itens de playlists sem precisar montar comandos manualmente.

Baixar para Windows

Recomendado para usuários finais: baixe o executável único da Release stable e confira o hash SHA-256 que acompanha o arquivo. O ZIP de código-fonte é para desenvolvedores e auditoria.

Baixar EXE oficial (stable) Código-fonte (desenvolvedores)

A Release stable deve conter ChatGPTMediaDownloader.exe e SHA256SUMS.txt. Caso falte um desses arquivos, não há ainda um pacote executável pronto para atualizar automaticamente.

Principais recursos

  • Vídeo em resoluções disponíveis até 4K.
  • Áudio MP3 com opções de bitrate.
  • Análise e seleção individual dos itens da playlist.
  • Configuração por item e processamento em sequência ou paralelo limitado.
  • Documentação, testes e código-fonte acessíveis publicamente.

Transparência e segurança

O projeto não foi criado para conter vírus ou funcionalidades maliciosas e não há malware intencional conhecido. Mesmo assim, nenhum projeto pode prometer honestamente que todos os executáveis estão 100% livres de vírus ou de falsos positivos sem auditoria independente. Baixe somente pelas releases oficiais, confira o SHA-256 e escaneie o arquivo com seu antivírus.

Este é um projeto independente e não é afiliado, patrocinado ou certificado pela OpenAI. Use-o apenas com mídia que você tem autorização para salvar.
